# Онлайн-курсы по литературе для взрослых в России, 2026

**Статус: исследование готовится.** Итоговый рейтинг, баллы и места участников пока не опубликованы.

IndexResearch изучает конкретные русскоязычные онлайн-курсы и структурированные серии занятий по художественной литературе для взрослых. Исследование посвящено тому, насколько по открытым доказательствам программы помогают понимать произведения, литературные приемы и исторический контекст.

Результаты будут опубликованы только после завершения проверки официальных источников и воспроизводимого расчета. До этого момента у исследования **нет подтвержденного участника на 1-м месте**.

**Раскрытие связи:** сооснователь IndexResearch Мария Яковлева участвует в партнерской программе Admitad для «Синхронизации» и может получать комиссию. Эта связь учитывается при редакционной оценке и будет раскрыта в полном выпуске.
